# QUSU Editor

面向微信公众号研究文章的模块化可视化排版编辑器。纯前端，文章、图片和历史记录均在本机浏览器处理，无登录、后端或付费 API。

## 运行

普通用户可从 [GitHub Releases](https://github.com/Acerocloud/qusu-editor/releases) 下载 Windows EXE 或 macOS DMG 安装包，无需 Node.js。运行程序会自动打开默认浏览器，在 `http://127.0.0.1:17863/` 编辑，文章保存到当前浏览器本机存储。程序在托盘或菜单栏常驻，可重新打开页面或退出。不同平台的下载选择、签名提示和旧文章迁移见 [安装说明](docs/RELEASE_NOTES.md)。

开发者可执行 `pnpm desktop` 启动桌面版；`pnpm dist:win` / `pnpm dist:mac` 在对应平台打包。推送 `v*` 标签后，GitHub Actions 自动构建 Windows x64 / ARM64、macOS Intel / Apple 芯片安装包，全部构建成功才发布 Release。

需要 Node.js 20.19+ 或 22.12+（建议当前 LTS）。

```bash
npm install
npm run dev
```

默认地址：<http://127.0.0.1:5173/>。

```bash
npm run build
npm test
npm run preview
```

本项目也支持 pnpm，附带 `pnpm-lock.yaml`：`pnpm install`、`pnpm dev`、`pnpm build`、`pnpm test`。此环境 npm 不在 PATH，已用内置 pnpm 完成安装，并通过 pnpm run build 与 pnpm run test 验证相同的 package.json 脚本。

Windows 可双击 `启动编辑器.cmd`。启动器优先使用系统 Node，再使用本机 Codex 内置 Node，无需 npm 在 PATH 中。它会启动服务并自动打开浏览器；重复启动复用已有服务；失败会保留错误信息。使用期间请保留启动窗口，按 Ctrl+C 停止服务。需要已经安装依赖。

## 使用

- 首次打开加载通用文章示例，展示全部 18 种基础模块、分割线、两种滚动图片模块及引用正文，共 22 种。
- 点击素材卡，在选中模块后插入；未选中时追加。拖动素材卡可在模块间插入。
- 模块侧边独立手柄排序；旁边提供插入正文、复制和删除。模块之间的加号提供全部模块菜单。
- 标题、编号、图注和单元格直接编辑。正文、摘要、引用和观察框使用独立 Tiptap 实例，支持格式、列表和安全粘贴。
- 右侧调整文字、颜色、间距、边框、指标数量、表格行列、图片和参考条目。
- 顶栏直接重命名文章；桌面 / 手机视图模拟 677 / 375px 阅读宽度；预览窗口使用微信 HTML 序列化器。
- `Ctrl+Z` / `Ctrl+Shift+Z` 撤销重做画布操作；正文编辑时优先使用 Tiptap 文字历史。画布焦点下 `Ctrl+D` 复制，`Delete` 删除选中模块。结构化输入框保留浏览器输入行为，顶栏撤销可恢复其内容修改。
- 自动保存有 450ms 防抖。连续内容或样式变更在 900ms 内合并历史，最多保存 80 个会话历史快照。刷新恢复当前文章，Undo 历史仅保留在当前会话。
- 文章库和模板库的主存储为 IndexedDB；IndexedDB 不可用时回退为完整 localStorage 保存。空间不足显示明确错误，请使用 JSON 备份。
- 本地图片支持 PNG / JPEG / GIF / WebP，单张最大 3MB；数据 URL 持久化在 IndexedDB 项目内，避免失效 object URL。新建或切换文章前先保存当前文章，每篇文章独立保留。

## 文章与模板

左侧工作空间提供「文章 / 模板 / 模块」三个标签，可收起和展开。「文章」支持新建、搜索、保存和切换；编辑时按文章自动保存，切换前会先保存，保存失败则保留原文章。切换文章后撤销记录重置，避免跨文章误操作。旧版本当前文章会自动纳入文章列表。

在「模板」填写名称并保存当前排版，模板包含文字、样式和本地图片。点击模板会建立独立的新文章，后续编辑不会修改模板。JSON 导入仍修改当前文章；若要单独保留，请先新建文章再导入。数据仅保存在当前浏览器，建议每篇重要文章定期导出 JSON。

## 导入与导出

导入 JSON 恢复完整模块、稳定 ID、样式和图片。导入会替换画布，可撤销。

导出提供五种明确区分的操作：

1. **复制富文本排版**：ClipboardItem 同时写入 `text/html` 与 `text/plain`。失败时尝试 copy 事件兼容方案，再失败则打开独立富文本区域，引导选中后 Ctrl+C。
2. **复制 HTML 源码**：复制普通代码文本，不用于直接粘贴公众号。
3. **下载微信发布版 HTML**：纯净内联样式文章，含 UTF-8 和 viewport 文件头，不包含编辑器 DOM、class、React 属性或 JavaScript。
4. **下载可编辑 HTML**：包含相同阅读版内容，附加转义的项目恢复注释。重新导入可恢复为原模块。发布请用微信发布版，避免把项目恢复信息带入公众号。
5. **保存 JSON 项目**：带 `schemaVersion: 1`，作为最完整的离线备份与恢复格式。

普通外部 HTML 和纯净微信发布版 HTML 会经过 DOMPurify 清理，尽量恢复正文、图片和真实表格。它们没有模块恢复信息，无法无损恢复原模块类型和样式。无损编辑往返请使用 JSON 或可编辑 HTML。

微信序列化器使用独立字符串生成逻辑，完全不读取画布 DOM。作者信息和指标使用 table，所有核心样式内联；富文本限制允许标签、链接协议和属性。

公众号后台会清理或调整部分 CSS，也可能限制外链图片，无法保证 100% 保留排版。本地图片发布时导出为文字占位框，它不是图片，公众号不会为它提供“替换图片”按钮。普通图片可删除占位框后重新插入；滚动相册应先在公众号上传图片，将可用的素材图片 URL 填回本编辑器对应图片的 URL 字段，再重新复制或导出排版。请粘贴后检查字体、间距、表格和图片。

## 工程结构

- `src/types.ts`：按模块类型区分的联合类型。
- `src/blocks/registry.ts`：名称、分组、默认内容及样式。
- `src/blocks/renderers.tsx`：各模块编辑渲染器与字段控件。
- `src/components/`：画布、素材库、属性面板及 Tiptap 编辑器。
- `src/store/editor.ts`：Zustand 文档状态、操作历史及自动保存。
- `src/lib/serializer.ts`：独立微信 HTML 序列化器与共享布局参数。
- `src/lib/project.ts`：版本校验、安全导入及项目恢复。
- `src/lib/storage.ts`：IndexedDB 主存储与 localStorage 回退。
- `src/lib/clipboard.ts`：富文本复制、回退及下载。

新增模块时扩展 ContentMap，并在 registry、renderers、serializers 映射中提供定义；TypeScript 会检查遗漏，避免多个复杂 switch。

## 验证

`npm test`：15 项核心测试覆盖模块导出、文本转义、富文本清理、资源 URL、JSON / 可编辑 HTML 往返、错误 schema、重复 ID、外部 HTML 转换及历史操作。

端到端测试默认使用 Windows 已安装的 Edge，先启动开发服务器，然后：

```bash
npx playwright test
```

其他平台可在 `playwright.config.ts` 中移除 `channel: 'msedge'`，并运行 `npx playwright install chromium`。

4 项浏览器测试覆盖真实鼠标拖拽插入与排序、内容保留、复制删除撤销重做、直接编辑、样式调整、表格编辑、刷新恢复、剪贴板 HTML / 纯文本、HTML 下载、安全导入和本地图片上传持久化。输入中文已经测试；真实操作系统中文输入法候选 / composition 场景仍建议在你的日常浏览器手动确认。



## 新增图片样式

- **长图纵向滚动**：在「图片与表格」中插入，上传单张长图。窗口固定为 1:1 正方形，右侧调整宽度时高度自动同步；完整原图保留，框内可上下滑动。替换图片请使用右侧上传控件。
- **多图横向滑动**：可单张上传或批量添加，最多 20 张。批量上传优先填充空图片位置；每张图片支持说明、替换、删除和前后移动。所有新旧相册固定为 1:1 居中裁剪预览，开屏露出少量下一张。触屏左右滑动，桌面可使用横向滚动条、触控板或箭头。点击图片查看完整原图，可放大查看；原始图片不被修改。导出的远程图片带原图链接，公众号粘贴后的滚动、裁剪与点击效果需要手机预览确认。
- 新模块支持 JSON / 可编辑 HTML 往返和 IndexedDB 保存；旧项目可以直接从素材库插入新模块，原文章不会被自动修改。
- 滚动发布版使用内联 overflow 样式，无脚本、SVG 或编辑器按钮。公众号可能清理滚动相关样式；图片上传到公众号后请手机预览验证，不能保证所有微信版本保留效果。导出区与复制成功提示均提醒检查。


## 引用正文与局部文字样式

在「正文内容」中插入「引用正文」，默认使用浅灰蓝背景、灰蓝文字和左侧细线，可在模块属性中调整背景、字号和边距。

所有文字样式统一在右侧「文字与颜色」面板修改。选中正文中的几个字后，面板自动切换为「选中文字」，调整字色、字号、背景高亮和字重只影响选区；点击「整段文字」则调整整个模块，原选区保留，可随时切回局部设置。加粗、斜体、下划线、链接、列表和清除格式也位于右侧面板。局部格式会随项目保存，并保留在预览、HTML 导出及富文本复制中。

## 标准配色与撤销

每个颜色控件右侧的下拉箭头都提供相同的固定配色，包含「品牌与正文」「深色强调」「正文背景」「文字高亮」四组。品牌主色为曲速金 #E3BA35、深海蓝 #05183B，搭配正文黑、辅助灰蓝、强调砖红、纯白，以及金、蓝、灰蓝、绿的实色背景和金、蓝、绿、红的明显高亮（均为不透明色，适合白底正文）。左侧色块仍可选择自定义颜色。

正文及右侧属性面板中的 Ctrl+Z 使用文章统一撤销记录；每次局部改色、字号、高亮等格式操作均单独记录。Ctrl+Shift+Z 或 Ctrl+Y 重做，与顶部撤销、重做按钮保持一致。

深色强调提供深朱红 #8B1E24、酒红 #741B3A、深赭红 #74342B，以及深金黄 #8A6500、琥珀黄 #795300、深土黄 #69501A；正文黑、辅助灰蓝和砖红也加深，便于白底正文强调。
